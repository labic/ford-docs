LABIC / UFES · Pesquisa acadêmica

Pesquisar começa por compreender os dados.

O Ford é uma ferramenta interna de coleta e processamento de dados de plataformas digitais, que apoia a pesquisa no Laboratório de Internet e Ciência de Dados (LABIC), da Universidade Federal do Espírito Santo (UFES), Brasil.

Research · Data · Society

01 / Sobre o Ford

Uma ferramenta de pesquisa, feita para o laboratório.

O Ford apoia a investigação acadêmica de plataformas digitais por meio da coleta e análise interna de dados.

É utilizado por pesquisadores e integrantes autorizados do LABIC. O Ford é uma ferramenta interna, sem fins comerciais, sem interface pública de acesso e sem cobrança de acesso.

O Ford utiliza os Serviços de API do YouTube, incluindo a YouTube Data API v3, para coletar internamente dados públicos de vídeos e comentários. Pesquisadores analisam dados armazenados em banco de dados em nuvem e arquivos CSV locais. Este site documenta o cliente; ele não coleta dados do YouTube.

02 / Fluxo de pesquisa

Da coleta à investigação.

01

Coleta

Integrantes autorizados coletam dados internamente para pesquisa.

02

Processamento

Scripts processam as informações coletadas para uso na pesquisa.

03

Análise

Pesquisadores examinam os dados no contexto de seus estudos.

04

Produção de conhecimento

As pesquisas podem contribuir para produções e debates científicos.

03 / Contexto institucional

Pesquisa conectada ao conhecimento público.

LABIC é o Laboratório de Internet e Ciência de Dados da UFES. Seu trabalho relaciona pesquisa sobre internet, dados e sociedade.

PYSA é uma iniciativa de divulgação científica relacionada às atividades do laboratório. Ele não é uma interface pública do Ford.
