Finalidade e acesso

O Ford é uma ferramenta interna e não comercial de pesquisa acadêmica do LABIC da UFES. Não é comercializado nem oferecido mediante cobrança. O acesso é restrito a integrantes autorizados do laboratório, e o sistema não possui interface pública de acesso.

Uso responsável

Os operadores autorizados devem usar o Ford para fins institucionais e acadêmicos e observar as regras institucionais, obrigações de privacidade e requisitos do YouTube aplicáveis.

Serviços de API e termos do YouTube

O Ford utiliza os Serviços de API do YouTube, incluindo a YouTube Data API v3. Ao usar o Ford, os operadores autorizados concordam com os Termos de Serviço do YouTube naquilo que for aplicável e devem observar os Termos de Serviço dos Serviços de API do YouTube e as Políticas para Desenvolvedores aplicáveis ao seu trabalho.

Uso e redistribuição de dados

Os dados da API do YouTube não podem ser usados, divulgados ou redistribuídos de forma incompatível com os termos e políticas aplicáveis da API. Os resultados de pesquisa estão sujeitos a esses requisitos e às regras institucionais aplicáveis.

Contato institucional

Dúvidas sobre o Ford e estes termos podem ser encaminhadas pela página de contato do LABIC. O Ford não é patrocinado nem endossado pelo Google ou YouTube.
